# Definition of Done (DoD)

Criterios de aceptación que debe cumplir una historia de usuario para considerarse terminada.

- [ ] Código implementado y revisado
- [ ] Pruebas unitarias/integración ejecutadas y pasando
- [ ] Documentación actualizada
- [ ] Desplegado en ambiente de pruebas
- [ ] Aceptado por el Product Owner / contraparte
