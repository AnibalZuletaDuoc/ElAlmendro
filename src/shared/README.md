# Shared — contratos compartidos

Tipos TypeScript comunes al backend y al frontend. Usar un solo lenguaje en
todo el sistema permite que estos tipos sean la única definición de los datos
que cruzan la frontera HTTP.

Contiene los estados del dominio, los DTO de respuesta y los nombres de los
eventos de dominio difundidos por socket.

Se consume como workspace de npm: `@timeflow/shared`.
